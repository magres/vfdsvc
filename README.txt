vfdsvc — часы и иконки на переднем LED-дисплее приставки Android TV
====================================================================

Кратко: ваш бокс (например, на Tanix TX92) показывает время «12:34» с мигающим
двоеточием и иконками состояния (Wi-Fi, LAN, USB) на передней панели, как и
положено, БЕЗ перепрошивки. Всё работает через ADB с обычного ПК, установка —
двойной клик. Полный откат — тоже двойной клик.

УСТАНОВКА (Tanix TX92, любой «тонкой» кастомной прошивке с root):
 1. Распакуйте архив.
 2. Узнайте IP приставки: Настройки -> Сеть (адрес вида 192.168.1.100)
    или посмотрите в личном кабинете вашего роутера.
 3. Дважды кликните install_windows.bat, выберите [1] и введите IP.
    Скрипт сам: подключится, проверит root, сделает резервную копию,
    установит драйвер и перезагрузит приставку.
 4. Подождите 30–60 секунд после загрузки — дисплей покажет часы.
 5. Передумали? Снова запустите install_windows.bat и выберите [0].

Если консоль закрывается сразу — запускайте через cmd (Пуск -> cmd ->
перейдите в папку cd /d путь\к\папке -> install_windows.bat).
Если пишет «нет root» — прошивка без root: см. README (полный) в репозитории.

Настройка (яркость/поведение в стендбае): файл conf\tx92-vfd.conf,
правьте блок в конце (brightness, standby, icons), затем заново [1].

ENGLISH SHORT:
 1. Unzip. 2. Find the box IP (Settings->Network). 3. Double-click
 install_windows.bat, choose [1], enter IP. 4. Wait ~1 minute - clock shows.
 5. To roll back: run again and choose [0]. Linux/macOS: ./scripts/install.sh <IP>.
